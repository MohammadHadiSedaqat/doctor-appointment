# وب‌سایت دکتر فاضل صداقت

React + Vite، متصل به Base44؛ محتوای عمومی ارتوپدی در مخزن نگهداری می‌شود و اطلاعات حساب و پرونده از بک‌اند دریافت می‌شود.

## اجرای محلی

Node.js نسخهٔ ۲۰ یا جدیدتر لازم است. در اولین نصب `npm ci` را اجرا کنید. فایل `.env.local` شامل شناسهٔ اپ و آدرس بک‌اند است؛ رمز یا توکن را در متغیرهای `VITE_*` قرار ندهید.

```bash
npm run dev
```

نشانی معمول: http://localhost:5174 . اگر این پورت قبلاً اشغال باشد، Vite خودکار پورت آزاد بعدی را در خروجی ترمینال اعلام می‌کند. برای توقف `Ctrl+C` را بزنید. این حالت، فرانت‌اند محلی با بک‌اند میزبانی‌شده است. درخواست‌های ثبت داده به همان بک‌اند ارسال می‌شوند؛ در تست‌ها دادهٔ واقعی ثبت نکنید.

```dotenv
VITE_BASE44_APP_ID=6a919a151ba82d7fb087375a
VITE_BASE44_APP_BASE_URL=https://hungry-prime-med-flow.base44.app
```

برای توسعهٔ بک‌اند محلی، پس از ورود و اتصال رسمی CLI به اپ، از `npx base44 dev` استفاده کنید. داده‌های بک‌اند محلی موقتی‌اند. هنگام استفاده از آن، سرور دوم Vite را جداگانه اجرا نکنید.

## ساخت و بررسی

```bash
npm run lint
npm run typecheck
npm run build
npm test
```

`build` ابتدا بستهٔ Vite و سپس HTML صفحات عمومی را در سه زبان تولید می‌کند. `npm test` شامل آزمون زمان‌بندی، پارامترهای ورود و خروجی SEO است؛ آن را بعد از build اجرا کنید. محتوای خروجی در `dist` است. `npm run preview` برای بررسی همان خروجی استفاده می‌شود.

## ساختار محتوا

- `src/config/site.js`: تنها منبع اطلاعات تأییدشدهٔ نام، تخصص، تماس، نشانی، شماره نظام پزشکی و عکس پزشک. مقادیر نامعلوم خالی می‌مانند.
- `src/data/services.js`: فهرست مشترک خدمات و متن سه‌زبانه؛ قیمت‌های ۱۰۰۰ تومان و زمان‌ها فعلاً موقت‌اند.
- `src/i18n/`: ترجمه‌ها و مسیرهای زبان؛ فارسی در ریشه، انگلیسی زیر `/en/` و عربی زیر `/ar/`.
- `src/components/PublicLayout.jsx`: هدر و فوتر مشترک؛ صفحات نباید آن‌ها را دوباره اضافه کنند.
- `src/seo/` و `scripts/prerender.mjs`: متادیتا، دادهٔ ساختاریافته، HTML اولیه، robots و sitemap.
- `src/lib/booking.js`: قواعد قابل‌آزمون زمان‌های نوبت؛ رزرو نهایی به پیاده‌سازی تراکنش سمت سرور نیاز دارد.

## وضعیت امکانات

صفحات معرفی پزشک و خدمات به دادهٔ آنلاین وابسته نیستند. شکست دریافت داده، به‌معنای «زمان خالی»، «بدون سابقهٔ پزشکی» یا «ثبت موفق» نمایش داده نمی‌شود. نوبت‌دهی قطعی تا پیاده‌سازی بررسی اتمیک ظرفیت و قیمت در بک‌اند غیرفعال است. برای این قسمت، دریافت اوقات مجاز باید فقط زمان‌های قابل رزرو را برگرداند و هیچ مشخصات بیماری را عمومی نکند.

مجوزهای سطح رکورد Base44 برای پرونده‌ها، نسخه‌ها و بیماران باید پیش از فعال‌سازی عملیاتی در محیط واقعی بررسی شوند. فیلتر سمت مرورگر جایگزین این مجوزها نیست. تغییرات این مخزن به‌تنهایی آن مجوزها را تأیید نمی‌کند.

اپ فعلی هنوز منتشر نشده؛ خطای `403 / not_deployed` مانع امکانات وابسته به بک‌اند است. هیچ انتشار یا تغییر مجوز خودکاری انجام نمی‌شود.

## آماده‌سازی انتشار و SEO

راهنمای [SEO](docs/SEO.md) را بخوانید. تا تأیید دامنه و انتشار، ایندکس‌گذاری خاموش است. دامنهٔ عمومی با آدرس بک‌اند دو تنظیم مجزا هستند. برای انتشار تأییدشده، دامنهٔ واقعی را تنظیم و خروجی را دوباره بسازید:

```dotenv
VITE_PUBLIC_SITE_URL=https://YOUR-VERIFIED-DOMAIN
VITE_SITE_INDEXABLE=true
```

این مثال را عیناً کپی نکنید؛ مقدار دامنه باید واقعی باشد. فایل‌های `.env*` محلی‌اند و در Git ثبت نمی‌شوند. سایت پزشکی باید اطلاعات تماس و مدارک معتبر، تعرفهٔ تأییدشده و سیاست حریم خصوصی متناسب با عملکرد واقعی داشته باشد. رتبهٔ گوگل با کد تضمین نمی‌شود.

انتشار فقط پس از تأیید مالک، از داشبورد Base44 و مطابق روند اتصال Git انجام می‌شود؛ از push/deploy ناخواسته خودداری کنید.
